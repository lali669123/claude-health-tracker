# 生成周报

1. 周期：截至最近一个周六的 7 天（上周日到本周六）。文件名用这个周六所在的 ISO 周：`data/reports/weekly/YYYY-Www.md`。
2. 文件已存在时，先改名为 `YYYY-Www-旧版.md` 保留，再写新的。
3. 数据来源：`data/structured/` 四个 CSV、`data/config/goals.json`、这 7 天已有的日报。
4. 内容：
   - 执行摘要：亮点、问题、综合评分。
   - 目标达成度：体重（7 天平均和上周对比）、热量、蛋白质、睡眠、训练次数。
   - 趋势与关联分析（例如睡眠时长和次日 HRV）。数据少于 4 天时只描述，不下结论。
   - 数据缺口清单。
   - 下周目标：A（必须做到）/ B（争取）/ C（有余力再做）。
5. 缺失的数据写明缺失，不要估算补齐，不要编造对比数据。不要改 CSV。
