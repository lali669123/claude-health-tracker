# 生成日报

1. 日期默认今天；用户说“昨天”“补记”时用对应日期。
2. 该日期在 `daily_metrics.csv` 和 `wearable.csv` 里没有任何手环数据（夜间睡眠、步数、静息心率都为空）时，不生成日报，告诉用户缺什么。
3. `data/reports/daily/YYYY-MM-DD.md` 已存在时，先问用户是否重新生成。
4. 数据来源：`data/structured/` 四个 CSV，`data/config/profile.json`、`goals.json`。
5. 内容：
   - 营养：各餐和全天热量、蛋白质，对比目标。
   - 睡眠与恢复：夜间睡眠、评分、静息心率、HRV。
   - 活动与训练。
   - 热量缺口：基础代谢（Mifflin-St Jeor：10×体重 + 6.25×身高 − 5×年龄 + 5，男性；女性最后 −161）+ 手环活动热量 − 摄入。体重用该日期或之前最近一次实测，写明体重日期。注明消耗是估算。
   - 近 7 天趋势：只用有数据的天，写明天数。
   - 评分（饮食、睡眠、活动、综合，/10）及理由。
   - 明日行动 3-5 条，要具体。
6. 缺失的数据写明缺失，不要估算补齐，不要编造对比数据。
7. 保存报告；在 `data/logs/daily/YYYY-MM-DD.md` 末尾追加简短摘要。不要改 CSV。
