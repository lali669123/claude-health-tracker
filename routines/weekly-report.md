# 定时周报（可选）

新建定时任务，时间设每周六 20:45 左右，贴入下面的提示词，把 `<DATA_DIR>` 换成你的 `data` 文件夹绝对路径。

---

生成健康周报。数据目录（绝对路径，只用这一份）：`<DATA_DIR>`

1. 周期：截至本周六的最近 7 天（上周日到本周六）。任务推迟到周日或之后运行，仍按刚过去的周六计算。
   文件名用这个周六所在的 ISO 周：`reports/weekly/YYYY-Www.md`。文件已存在（例如提前手动运行过），先改名为 `YYYY-Www-旧版.md` 保留，再写新的。
2. 按项目里 `.agents/skills/weekly-report/SKILL.md` 的内容生成周报。
3. 缺失的数据写明缺失，不要估算补齐，不要编造对比数据。
4. 除了新周报和旧版改名，不要修改任何文件，尤其是 `structured/` 下的 CSV。
5. 最后输出周报摘要：综合评分、两三条亮点和问题、下周最重要的一件事。
