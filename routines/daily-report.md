# 定时日报（可选）

在 Claude 桌面应用里新建一个定时任务（侧边栏 Scheduled），时间设每晚 23:30，把下面的提示词贴进去，并把 `<DATA_DIR>` 换成你的 `data` 文件夹绝对路径。

定时任务会在新的对话里运行，不记得你的日常对话，所以提示词里写全了规则。它只读 CSV、只写报告。

---

为健康日报做每晚检查。数据目录（绝对路径，只用这一份）：`<DATA_DIR>`

1. 检查今天和前两天（任务可能过了零点才运行）。
2. 对每个日期：
   - `reports/daily/YYYY-MM-DD.md` 已存在 → 跳过，不覆盖。
   - `structured/daily_metrics.csv` 和 `structured/wearable.csv` 里该日期没有任何手环数据（夜间睡眠、步数、静息心率都为空）→ 不生成，记下这个日期。
   - 其余情况按项目里 `.claude/skills/daily-report/SKILL.md` 的内容生成日报；不是今天的日期，标题注明「补记日报」。
3. 缺失的数据写明缺失，不要估算补齐，不要编造对比数据。
4. 保存到 `reports/daily/YYYY-MM-DD.md`，在 `logs/daily/YYYY-MM-DD.md` 末尾追加简短摘要。除这两个文件外不要修改任何文件，尤其是 `structured/` 下的 CSV。
5. 最后输出：生成了哪些日期的日报（附综合评分和明日重点），哪些日期因缺手环数据没生成。提醒用户把手环截图发到日常记录的对话，不要在这个定时任务对话里记录，免得重复。
